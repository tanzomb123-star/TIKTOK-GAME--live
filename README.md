# Tower Live

เกม Tower Defense ที่ผู้ชม TikTok Live เล่นร่วมกันผ่านคอมเมนต์และไลก์ เพื่อปกป้องบ้านสตรีมเมอร์จาก 10 เวฟ

## ก่อนไลฟ์ (สำคัญ)
อ่าน [`docs/compliance.md`](docs/compliance.md) ให้ครบทุกข้อ และอ่านกฎทางการใน TikTok (LIVE Center > Rules and Guidance)
ข้อมูลในไฟล์นั้นยังไม่ได้ยืนยันกับข้อความทางการ

หลัก ๆ: อย่าพูดหรือเขียนชวนให้ส่งของขวัญ • ไม่มีรางวัลมีมูลค่า • ห้ามใช้ `npm run mock` ระหว่างไลฟ์จริง
(ระบบจะไม่ยอมรันถ้าตั้ง `TIKTOK_USERNAME` ไว้ด้วย)

ตัวเชื่อมใช้ `tiktok-live-connector` ซึ่งไม่เป็นทางการ และส่งคำขอเซ็นชื่อ WebSocket ผ่านเซิร์ฟเวอร์ภายนอก (Euler Stream)
อาจพังเมื่อ TikTok เปลี่ยนระบบ และบัญชีของคุณอาจได้รับผลกระทบหากผิดข้อกำหนด

## ติดตั้ง
```bash
npm install
npm test
```
ต้องใช้ Node.js 20 ขึ้นไป

## ลองเล่นแบบไม่ต้องไลฟ์
```bash
npm run mock   # เปิดผู้ชมจำลอง (มีป้าย DEMO บนจอ)
npm run dev    # เปิดเกมที่ http://localhost:5173
```
คีย์บอร์ดจำลอง: `1` `2` `3` เรียกทหาร • `L` ไลก์ x5 • `G` ของขวัญเล็ก • `H` ของขวัญกลาง • `B` ของขวัญใหญ่

## ไลฟ์จริง
```bash
TIKTOK_USERNAME=ชื่อช่องของคุณ npm run server
npm run dev
```
เปิดไลฟ์บน TikTok ก่อน แล้วจับภาพ `http://localhost:5173` ด้วย OBS (Browser Source ขนาด 960x540)
หรือ Window Capture แล้วส่งขึ้น TikTok LIVE Studio
ตรวจว่ามีไฟล์ `logs/events-วันที่.jsonl` และมีบรรทัดใหม่เมื่อมีคนพิมพ์คอมเมนต์ในไลฟ์ ถ้าไม่มี แปลว่าตัวเชื่อมใช้ไม่ได้
(log เก็บแค่ชนิด event รหัสย่อของผู้ใช้ และตัวเลขคำสั่ง ลบเองหลัง 7 วัน)

## กติกาเกม
| ผู้ชมทำ | ผลในเกม |
|---|---|
| คอมเมนต์ `1` / `2` / `3` | เรียกทหาร / นักธนู / อัศวิน (ใช้พลังงาน 5 / 8 / 12) |
| ไลก์ | เติมพลังงานให้ทุกคน (และมีพลังงานเกิดเองช้า ๆ) |
| ของขวัญ 1-9 เพชร | อัปเกรดหอคอย (สูงสุด 5 ระดับ ถ้าเต็มแล้วได้พลังงานแทน) |
| ของขวัญ 10-99 เพชร | ล้างศัตรูทั้งจอ |
| ของขวัญ 100+ เพชร | บอสช่วย 20 วินาที |

ของขวัญแบบกดต่อเนื่องนับทีละชิ้นทันที (ไม่รอจบการกด)
ผลของขวัญแน่นอน ไม่มีการสุ่ม และเกมชนะได้โดยไม่ต้องมีของขวัญ (มีเทสต์ยืนยัน)
ปรับค่าทั้งหมดได้ที่ `game/config.js`

## ปรับสมดุลหลังไลฟ์ทดสอบ
ค่าเริ่มต้นจูนจากการจำลองในเครื่อง (รอบละราว 6 นาทีกับผู้ชมน้อย) ยังไม่เคยทดสอบกับผู้ชมจริง
ถ้ารอบสั้น/ยากเกินไป ปรับ `waves.*` และ `energy.*` แล้วรัน `npm test` (เทสต์ "ชนะได้โดยไม่มีของขวัญ" ต้องผ่าน)
